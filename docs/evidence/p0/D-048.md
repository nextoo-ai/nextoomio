## Procedure

1. **AC1 (Given a rules response that names two required checks, when the pipeline waits for a pull request's checks, then it waits for exactly those two names):**
   - Implemented `get_required_checks(repo=REPO, role=None)` in `scripts/agent-pipeline.py`:
     - Queries the branch rulesets API on `main`: `gh_json(["api", f"repos/{repo}/rules/branches/main"], role=role)`.
     - Traverses rules of type `required_status_checks` and extracts check context/name identifiers from `parameters.required_status_checks`.
     - Stops with `Stop(1)` if the rules response cannot be parsed, contains no `required_status_checks` rule, or names no checks.
   - Updated `wait_for_ci(number, required_checks=None, issue=None, timeout=3600)`:
     - Accepts `required_checks` parameter, defaulting to `REQUIRED_CHECKS` if set or calling `get_required_checks()`.
     - Validates `all(states.get(name) == "SUCCESS" for name in required_checks)`.
     - Waits for strictly those names: does not succeed when only a subset has passed, does not succeed when extra unrequired checks pass, and succeeds immediately when all named required checks pass (even if an unrequired check is pending).
   - Tested offline in `run_self_tests()` Test 11:
     - Substituted rules API response naming two required checks: `Check Alpha` and `Check Beta`.
     - Verified `get_required_checks()` returns `{"Check Alpha", "Check Beta"}`.
     - Simulated PR status rollups:
       - Only `Check Alpha` SUCCESS: timed out waiting for `Check Beta`.
       - `Check Alpha` SUCCESS and unrequired `Check Extra` SUCCESS: timed out waiting for `Check Beta`.
       - `Check Alpha` SUCCESS and `Check Beta` SUCCESS: succeeded immediately (exit True).
       - `Check Alpha` SUCCESS, `Check Beta` SUCCESS, and `Check Extra` PENDING: succeeded immediately without waiting for `Check Extra`.

2. **AC2 (Given a rules response without a required_status_checks rule, or a failed request, when the pipeline starts, then it stops with exit status 1 and a message that names the rules on main):**
   - Updated `main()` in `scripts/agent-pipeline.py`:
     - At the very beginning of the run inside the main `try:` block, calls `required_checks = get_required_checks()`.
     - Sets global `REQUIRED_CHECKS = required_checks` and passes `required_checks=required_checks` to `wait_for_ci`.
     - When `get_required_checks()` raises `Stop(1, ...)` (missing rule, empty checks list, or failed API request), `main()` catches `Stop`, emits `say(str(stop))`, runs `cleanup_checkout` in `finally`, and returns exit status 1.
   - Tested offline in `run_self_tests()` Test 11:
     - Scenario 2a: Substituted rules response without `required_status_checks` rule (`[{"type": "deletion"}, {"type": "pull_request"}]`). Running `main(["189", "--role", "devops"])` exited with status 1 and emitted `"the rules on main name no required status checks"`.
     - Scenario 2b: Substituted rules response with empty `required_status_checks` list (`[{"type": "required_status_checks", "parameters": {"required_status_checks": []}}]`). Running `main()` exited with status 1 and emitted `"the rules on main name no required status checks"`.
     - Scenario 2c: Substituted failed API request (raising `Stop(1)`). Running `main()` exited with status 1 and emitted `"cannot read the rules on main: command failed (1): gh api repos/... (HTTP 500)"`.

3. **AC3 (Given the repository, when `grep -n "Yocto Layer Check" scripts/agent-pipeline.py` runs, then no match is found outside the self-tests):**
   - Removed the hardcoded set of required check names at the top of `scripts/agent-pipeline.py` (replaced with `REQUIRED_CHECKS = None`).
   - Isolated the string `"Traceability, Docs & Yocto Layer Check"` strictly to Test 8 inside `run_self_tests()`.
   - Executed `grep -n "Yocto Layer Check" scripts/agent-pipeline.py` and confirmed the only match is at line 907 inside `run_self_tests()` (which spans lines 441–1459).

4. **AC4 (Given the change, when `python3 scripts/agent-pipeline.py --test` runs, then it exits 0 and covers AC1 and AC2 with substituted responses, without network):**
   - Added Test 11 to `run_self_tests()` covering AC1 and AC2 completely offline using mocked `gh` and `pr_state` responses.
   - Executed `python3 scripts/agent-pipeline.py --test` and verified exit 0.

5. **Rules request against the real repository:**
