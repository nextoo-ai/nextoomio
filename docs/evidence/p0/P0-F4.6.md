## Procedure

1. Ran `cargo test --locked --manifest-path core/Cargo.toml` on the development workstation (macOS). All test binaries reported `0 failed`; the `nx-sysd` library tests reported `80 passed`, including the 23 tests in `core/crates/nx-sysd/src/commit_tests.rs` named below.
2. The tests use `MockSlotBackend` with simulated uptime, health reports, and selector reads, except `ac1_physical_selector_content_before_and_after_commit` and `ac5_physical_ssh_access_follows_the_key_file_on_the_selector_partition`, which run `PhysicalSlotBackend` against a temporary directory standing in for the selector partition (`NEXTOOMIO_SELECT_DIR`) and `FileJournalStorage` on disk, in separate engine instances standing in for separate processes.
3. Inspected the image configuration that the change relies on, without building it: `meta-nextoomio/recipes-nextoomio/nx-sysd/files/nextoomio-trial-watchdog.service` (runs `nx-sysd update trial-watchdog --deadline 120 --poll-interval 1000`, which now also commits the trial) and `meta-nextoomio/recipes-bsp/bootfiles/rpi-autoboot.bb` (selector `autoboot.txt` with `tryboot_a_b=1`).
4. Ran `make check` (documentation, document versions, evidence, i18n, bench scripts, Yocto layer validation).

## Missed targets

- **AC1 (hardware part) and AC4:** configuration inspected; not observed. The next ordinary boot after commit and the ten reboots of a committed transaction need the bench and an image built from this commit.
- **AC2, AC3, AC5:** demonstrated in software only; SSH confirmation from the workstation to a running trial on the device has not been run.
- **Power-loss safety of the selector write:** not established. The selector is replaced by writing a temporary file, flushing it, renaming it over `autoboot.txt`, and flushing the directory (interim selector operation, `ARCHITECTURE.md` section 3.6 step 6). Whether this rename is safe against power loss on the FAT selector partition, and how the firmware reads a selector interrupted mid-write, is the question of spike #17 (P0-F4.1); the D-026 recovery covers only an interruption the journal can see.
- **Image build:** no image was built from this commit.
