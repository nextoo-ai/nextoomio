# Evidence: D-038 Evidence check accepts heading-only section and defect filenames without three digits

- **Issue:** #163
- **Date:** 2026-11-14
- **Image version and commit:** none (repository only); check commit `79419b9` on `ops/D-038-evidence-check-accepts-a-heading` (`scripts/check_evidence.py`, `docs/evidence/p0/D-038.md`)
- **Hardware model and revision:** none (this defect concerns repository validation scripts, unit test suite, and verification evidence only)
- **Physical access needed:** none (nothing needed physical access to a device)

> [!IMPORTANT]
> Secrets, private keys, credentials, tokens, passwords, and addresses of private networks must not be recorded in evidence.

## Procedure

1. **AC1 (Heading-only sections rejected):**
   - In `scripts/check_evidence.py`, introduce `strip_heading_lines(text)` and `HEADING_LINE_RE = re.compile(r"^\s*#{1,6}(?:\s+.*)?$")` to strip markdown heading lines before checking whether a section body has non-empty content in `section_has_content()`.
   - Test against temporary evidence files containing only a subheading in `## Procedure` (e.g. `### Step 1`) or in `## Observed result` (e.g. `### Output`), verifying that the check fails with exit code 1 and explicitly names both the file path and the empty section.
   - Test a multi-heading section without body content (`### Step 1`, `### Step 2`, `#### Substep 2.1`) to ensure all heading lines are treated as no content.
   - Test a section with subheadings followed by genuine body text, ensuring it passes.

2. **AC2 (Defect filename convention `D-\d{3}`):**
   - In `scripts/check_evidence.py`, update `FILENAME_RE` from `^(?:P\d+-F\d+\.\d+|D-\d+)\.md$` to `^(?:P\d+-F\d+\.\d+|D-\d{3})\.md$` matching the backlog convention for defect identifiers (`D-<nnn>`, e.g. `D-038`).
   - Test temporary files named `D-1.md` and `D-0001.md`, verifying that both are rejected with exit code 1.
   - Test a temporary file named `D-038.md`, verifying that it is accepted.

3. **AC3 (Self-tests and existing evidence):**
   - Extend the self-test suite in `run_self_tests()` with unit test assertions for:
     - `D-1.md` and `D-0001.md` in the invalid filename test cases.
     - `D-038.md` in the valid defect filename test cases.
     - Heading-only `## Procedure` section failing and naming the file and `Procedure`.
     - Heading-only `## Observed result` section failing and naming the file and `Observed result`.
     - Valid section with subheadings and actual body content passing.
     - Multi-heading section without body content failing and naming `Procedure`.
   - Run `python3 scripts/check_evidence.py --test` and confirm all 26 assertions pass.
   - Run `python3 scripts/check_evidence.py` to confirm all repository evidence files (`docs/evidence/p0/P0-F8.3.md`, `docs/evidence/p0/P0-F8.5.md`, and `docs/evidence/p0/D-038.md`) pass.
   - Run `make check-evidence` and `make check`.
