## Procedure

1. **AC1 (Existing remote branch without open pull request uses `<branch>-2` at `origin/main`, keeping existing remote branch unchanged):**
   - Updated `choose_branch(branch, pr=None, cwd=None)` in `scripts/agent-pipeline.py`:
     - With `pr=None`, inspects whether candidate branch names exist on `origin` using `git rev-parse --verify --quiet refs/remotes/origin/<candidate>`.
     - When `refs/remotes/origin/<branch>` already exists, iteratively checks numeric suffixes (`<branch>-2`, `<branch>-3`, ...) until finding the next unused name on `origin`.
     - Switches to and resets the selected local branch from `origin/main` using `git switch -C <candidate> origin/main`.
     - Does not delete, modify, or force-push the existing remote branch on `origin`.
   - Tested offline in a temporary git repository:
     - Initialized `d046_origin` repository on `main` with an initial commit `c_main`.
     - Created branch `ops/D-046-test` on `d046_origin` with commit `c_remote1` (simulating a branch left behind by a closed unmerged PR).
     - Cloned `d046_origin` into `d046_local`.
     - Verified pre-conditions in `d046_local`: `origin/ops/D-046-test` ref exists, while `origin/ops/D-046-test-2` does not exist.
     - Called `choose_branch("ops/D-046-test", pr=None, cwd=d046_local)`.
     - Verified post-conditions: returned branch is `ops/D-046-test-2`, `d046_local` is on branch `ops/D-046-test-2` pointing to `c_main`, and `d046_origin` branch `ops/D-046-test` is unchanged at `c_remote1`.

2. **AC2 (Existing `<branch>-2` on remote uses `<branch>-3`):**
   - Verified numeric suffix iteration in `choose_branch()`:
     - When both `refs/remotes/origin/<branch>` and `refs/remotes/origin/<branch>-2` exist on `origin`, the while loop increments the suffix counter to `-3`.
   - Tested offline in a temporary git repository:
     - Created branch `ops/D-046-test-2` on `d046_origin` with commit `c_remote2`.
     - Switched `d046_local` back to `main`.
     - Called `choose_branch("ops/D-046-test", pr=None, cwd=d046_local)`.
     - Verified post-conditions: returned branch is `ops/D-046-test-3`, `d046_local` is on branch `ops/D-046-test-3` pointing to `c_main`, and existing remote branches `ops/D-046-test` and `ops/D-046-test-2` on `d046_origin` are unchanged.
