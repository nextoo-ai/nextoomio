   - Fixed all eight affected recipes and bbappends in `meta-nextoomio` to conform to Yocto 6.0 conventions:
     - `meta-nextoomio/recipes-connectivity/avahi/avahi_%.bbappend`: replaced `${WORKDIR}` with `${UNPACKDIR}`.
     - `meta-nextoomio/recipes-connectivity/networkmanager/networkmanager_%.bbappend`: replaced `${WORKDIR}` with `${UNPACKDIR}`.
     - `meta-nextoomio/recipes-connectivity/nftables/nftables_%.bbappend`: replaced `${WORKDIR}` with `${UNPACKDIR}`.
     - `meta-nextoomio/recipes-connectivity/openssh/openssh_%.bbappend`: replaced `${WORKDIR}` fallback with `${UNPACKDIR}`.
     - `meta-nextoomio/recipes-core/systemd/systemd_%.bbappend`: replaced `${WORKDIR}` with `${UNPACKDIR}`.
     - `meta-nextoomio/recipes-nextoomio/nextoomio-audio-profile/nextoomio-audio-profile_0.0.1.bb`: removed `S = "${WORKDIR}/sources"` and `UNPACKDIR = "${S}"`; set `S = "${UNPACKDIR}"`.
     - `meta-nextoomio/recipes-nextoomio/nextoomio-ssh-keys/nextoomio-ssh-keys_0.0.1.bb`: removed `S = "${WORKDIR}/sources"` and `UNPACKDIR = "${S}"`; set `S = "${UNPACKDIR}"`.
     - `meta-nextoomio/recipes-nextoomio/nextoomio-test-faults/nextoomio-test-faults_0.0.1.bb`: removed `S = "${WORKDIR}/sources"` and `UNPACKDIR = "${S}"`; set `S = "${UNPACKDIR}"`.
   - Extended `scripts/check_yocto_layer.py` to scan all recipes and bbappends in `meta-nextoomio` and fail if:
     - Pattern 1: `S` is set relative to `${WORKDIR}` (e.g. `S = "${WORKDIR}/..."`).
     - Pattern 2: Any assignment to `UNPACKDIR` is present (e.g. `UNPACKDIR = "${S}"`).
     - Pattern 3: `${WORKDIR}/` is used as the source of a `file://` item.
     Each error message identifies the relative file path and line number.
   - Added automated self-tests 21, 22, and 23 in `scripts/check_yocto_layer.py` covering each pattern with isolated temporary directory mutations, asserting that the check fails and outputs the exact file name and line number.
   - Executed `python3 scripts/check_yocto_layer.py --test` and `python3 scripts/check_yocto_layer.py`.
   - Executed `python3 scripts/check_evidence.py` and repository quality checks via `make`.
