## Procedure

1. **AC1 (Pipeline stops with exit status 1 and error message on session failure):**
   - Updated `agent(role, task, log, extra_paths=None, cwd=None)` in `scripts/agent-pipeline.py`:
     - After executing the session script via `subprocess.run(...)` and recording stdout to `log`, checks `if out.returncode != 0:`.
     - Raises `Stop(1, f"{role} session failed with exit status {out.returncode}; see log {log}")`.
     - When caught by `__main__`, prints the error message via `say()` and exits with status 1.
   - Verified in automated self-tests:
     - Configured a mock session script that fails with exit status 1 (simulating usage limit or token error).
     - Started role `reviewer` with `agent()`. Verified that `Stop` is raised with `status == 1`, and the error message names `reviewer`, status `1`, and points to the run log. Verified that the session failure message was written to the run log.
     - Configured a mock session script that fails with exit status 127.
     - Started role `developer` with `agent()`. Verified that `Stop` is raised with `status == 1`, and the error message names `developer`, status `127`, and points to the run log.

2. **AC2 (No calls changing issue labels or commenting on the issue on failure):**
   - Verified that raising `Stop(1)` inside `agent()` immediately aborts pipeline execution before callers can invoke `block()`, `deliver()`, or any GitHub issue mutation APIs.
   - Verified in automated self-tests with tracked `gh` calls during simulated reviewer failure, author failure, and QM failure:
     - Monitored all calls matching `gh issue edit`, `gh issue comment`, or `gh issue close`.
     - Verified that during role session failure, zero issue mutation calls are made (`gh_issue_mutations == []`), preserving the issue's labels (`state:ready` remains unchanged) and creating no comments.
     - Contrast check: confirmed that `block()` explicitly triggers `issue edit` and `issue comment`, proving that preventing `block()` on session failure avoids invalid issue state transitions.

3. **AC3 (`python3 scripts/agent-pipeline.py --test` exits 0):**
   - Added Test 7 to `run_self_tests()` in `scripts/agent-pipeline.py` covering AC1 and AC2 completely offline, without network access and without launching real AI roles.
   - Executed `python3 scripts/agent-pipeline.py --test` to confirm it exits 0.
   - Executed `python3 scripts/check_evidence.py` and `make check` to verify repository consistency, evidence validation, and quality gates.
