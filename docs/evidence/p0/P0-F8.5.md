## Missed targets

- Tokens, passwords, credentials, and private network addresses in evidence files are not detected by the automated script; only PEM private key blocks (`-----BEGIN ... PRIVATE KEY-----`) are detected. Reviewers and authors must inspect evidence files manually for sensitive network details or credentials (CQ-D8, CQ-R6).
- The commit hash pattern `\b[0-9a-f]{7,40}\b` validates hexadecimal character length and bounds offline without verifying existence against git commit history, and syntactically permits any 7+-digit decimal number or word composed solely of characters a–f.
- No physical bench hardware checks were performed; this enabler story concerns repository templates, offline validation scripts, documentation, and CI workflows only.
