   - Implemented `replace_commit_marker_in_text(text, commit_hash)` and `replace_commit_markers(paths, commit_hash, root=ROOT)` in `scripts/agent-pipeline.py`:
     - Restricts replacement exclusively to the `Image version and commit` metadata field line using regex `^(\s*(?:[-*]\s+)?(?:\*\*)?Image(?:\s+version)?(?:\s+and\s+commit)?(?::\*\*|\*\*:|:)\s*)(.*)$`.
     - Preserves all prose occurrences of `{{COMMIT}}` in section bodies (`## Procedure`, `## Observed result`, etc.).
     - In `deliver()`, reads the change commit hash (`git rev-parse HEAD`), invokes `replace_commit_markers()`, stages modified evidence files, and creates a follow-up commit (`Record change commit in evidence\n\nRefs #<issue>`) before pushing to `origin` and opening or updating the pull request.
   - Added automated self-test `test_d039_commit_marker_replacement` in `run_self_tests()` in `scripts/agent-pipeline.py` exercising `replace_commit_marker_in_text` and `replace_commit_markers` on an isolated git repository:

     - Verified `replace_commit_markers` updates only the `Image version and commit` field and leaves prose markers untouched.
     - Verified follow-up commit contains only the updated evidence file.
   - Executed `python3 scripts/agent-pipeline.py --test`.

       - When `is_main` is False: `{{COMMIT}}` in `img_val` is accepted as an author placeholder prior to pipeline delivery.

     - Test 21: Evidence file with `{{COMMIT}}` marker on branch (`is_main=False`) passes.
     - Test 22: Evidence file with unresolved `{{COMMIT}}` marker on main (`is_main=True`) fails and names the file.

     - Test 25: Evidence file with valid commit hash and `{{COMMIT}}` in prose on main (`is_main=True`) passes.
