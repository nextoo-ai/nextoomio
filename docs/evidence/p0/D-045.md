   - Updated `wait_for_ci(number, issue=None, timeout=3600)` in `scripts/agent-pipeline.py`:
     - Checks if `mergeStateStatus == "DIRTY"` or `mergeable == "CONFLICTING"`.
     - When a conflict with `main` is detected, resolves the issue identifier (from the `issue` argument or via regex `Refs #<issue>` in the pull request body).
     - Calls `block(target_issue, f"pull request #{number} conflicts with main.")`, which sets `state:blocked`, removes `state:ready`, posts a comment naming the conflict and the pull request, and raises `Stop(2, ...)`.
     - Stops waiting immediately on the first poll without sleeping or waiting for timeout.
   - Updated `main()` in `scripts/agent-pipeline.py` to pass `issue=issue` when calling `wait_for_ci(number, issue=issue)`.
   - Verified in automated self-tests:
     - Configured substituted PR states with `mergeStateStatus: "DIRTY"` and `mergeable: "CONFLICTING"` with empty `statusCheckRollup`.

2. **AC2 (Non-conflicting pull request with pending checks keeps waiting as before):**
