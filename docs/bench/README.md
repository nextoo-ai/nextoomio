# Bench tooling

This directory documents developer tooling for operating and deploying to the nextoomio hardware test bench.

## Tools

- [deploy.md](deploy.md): One-command deploy tool (`scripts/bench/deploy.py`) that uploads, validates, installs, trial boots, and remotely confirms images on the bench Raspberry Pi 4 + HiFiBerry Amp+ setup (P0-F5.1, [ROADMAP.md](../../ROADMAP.md) section 2.1, [ARCHITECTURE.md](../../ARCHITECTURE.md) section 4.1).
